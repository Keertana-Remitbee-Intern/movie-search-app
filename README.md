# CineFind

CineFind is a movie search web application that allows users to discover movies, search for specific titles, filter movies by genre, and view detailed movie information.

## Features

- Search for movies using the TMDB API
- Pagination for search results
- Explore the top 10 popular movies and top 10 top-rated movies
- Filter Explore movies by genre
- View detailed movie information, including rating, runtime, genre, plot, director, actors, release date, and language

## Tech Stack

- HTML
- CSS
- JavaScript
- Vite
- [TMDB API](https://www.themoviedb.org/))
